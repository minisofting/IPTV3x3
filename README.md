📺 Телеканал «3х3» (IPTV3x3)
Дерзкий. Убойный. Инди.
Добро пожаловать в официальный репозиторий телеканала «3х3» — независимой вещательной сети, созданной для продвижения инди-веб-анимации, обджект-шоу и самого безумного контента, который вы не увидите на обычном ТВ.
🚀 О проекте
«3х3» — это не просто плейлист. Это попытка доказать, что для создания крутого телеканала не нужны вышки и лицензии, достаточно GitHub, Cloudinary и любви к анимации. Мы транслируем дух раннего интернета и поддерживаем независимых авторов.
🛠 Техническая часть
Эфир организован на базе современных облачных технологий для максимальной стабильности:
Hosting: GitHub (для управления структурой и плейлистами).
CDN: Cloudinary (для быстрой доставки видеопотока без тормозов).
EPG: Собственная программа передач (3x3EndlessEpg.xml) для эффекта полного погружения в эфир.
📡 Как смотреть?
Чтобы подключиться к нашему «убойному» вещанию, используйте любой IP-TV Player (VLC, SimpleTV, OTTPlayer и др.):
Скопируйте ссылку на Raw файл нашего плейлиста:
https://githubusercontent.com
Вставьте её в ваш плеер.
Наслаждайтесь инди-анимацией 24/7!
